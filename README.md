## 🔀 Cambiar o crear una nueva rama

### # Ver las ramas locales

git branch

### Cambiar a una rama existente

git checkout Main

### O crear una nueva rama y cambiarte a ella

git checkout -b nueva-rama

## 📤 Subir tus cambios a GitHub

### Agregar todos los cambios

git add .

### Hacer un commit con un mensaje descriptivo

git commit -m "Descripción de los cambios"

### Subir los cambios a la rama correspondiente

git push -u origin Main o proyecto
